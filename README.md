# Zomato Restaurant Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato Restaurant Dataset using Python.

The objective is to clean the dataset, analyze restaurant trends, visualize important patterns, and generate business insights.

---

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Dataset

The dataset contains information about restaurants including:

- Restaurant Name
- City
- Cuisines
- Ratings
- Votes
- Average Cost for Two
- Online Delivery
- Table Booking

---

## Project Steps

### Step 1
Load and inspect the dataset.

### Step 2
Perform data cleaning.

### Step 3
Conduct Exploratory Data Analysis (EDA).

### Step 4
Create visualizations.

### Step 5
Generate business insights.

---

## Visualizations

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Pie Chart
- Correlation Heatmap

---

## Key Insights

- New Delhi has the highest number of restaurants.
- North Indian cuisine is the most popular.
- Inner City has the highest average restaurant rating.
- Jakarta has the highest average dining cost.
- Votes and ratings have a weak positive correlation.
